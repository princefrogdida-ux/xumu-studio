# 叙幕 Studio · AI 短剧无限画布工作台

目标：开发面向短剧制作的节点画布工具，让用户在同一个项目内组织剧本、角色、场景、分镜图片和镜头视频。

参考产品：[LibTV](https://www.liblib.tv/)。借鉴其创作场景，自建产品逻辑；目前未验证其登录后编辑器的全部交互，不以内部实现复刻为目标。

## Windows 安装版

应用版本 **0.1.0**，方案版本 **1.7**。下载 [Windows x64 安装程序](https://github.com/princefrogdida-ux/xumu-studio/releases/download/v0.1.0/Xumu-Studio-0.1.0-Windows-x64-Setup.exe)，或查看 [Release 与校验文件](https://github.com/princefrogdida-ux/xumu-studio/releases/tag/v0.1.0)。内置 Node 和依赖，安装后从开始菜单打开“叙幕 Studio”，使用本地浏览器工作台。

用户数据保存到 `%LOCALAPPDATA%\XumuStudio`，升级/卸载保留；退出时在控制台输入 `stop` 并回车。安装向导为英文，工作台为中文。首发未签名、真实调用默认关闭，具体真实模型仍待验收。[安装、配置、备份与发布验证](docs/WINDOWS_RELEASE.md) / [第三方许可与源码](THIRD_PARTY.md)。

## Windows 启动

环境：Node.js 24.14 或更新的 24.x、pnpm **11.19.0**（packageManager 固定版本）。当前电脑已安装并验证依赖；脚本优先寻找 PATH 中的 pnpm，找不到时使用 Codex 已安装的运行时，不修改全局 PATH。当前备用运行时 pnpm 为 11.25.0，doctor 会提示版本不匹配；既有依赖命令可运行，跨电脑安装复现优先使用 11.19.0。

```powershell
# 在克隆的 xumu-studio 目录中运行
.\scripts\project.ps1 dev
```

打开 [本地创作画布](http://127.0.0.1:4310/)。API 默认端口 4311；dev 同时启动独立 worker。终端输入 `stop` 并回车或按 `Ctrl+C`，等待“全部开发服务正常停止”。超时强停会明确提示，备份前需核实进程退出与端口释放。关闭网页不停止 worker。

首次在另一台电脑使用，先准备 Node.js 24.14+（24.x）和 pnpm 11.19.0，然后执行：

```powershell
.\scripts\project.ps1 install
.\scripts\project.ps1 dev
```

安装按锁文件联网下载，缓存与依赖保存在项目内，仅允许 esbuild 与 sharp 的安装脚本。网络超时可重试，不需要删除锁文件。2026-10-08 已在不复制依赖、data 或 .env 的独立目录，用 pnpm 11.19.0 完成联网安装、构建、测试与生产 API/worker 启动，供应链校验未禁用，见 [优化验收](docs/OPTIMIZATION_VALIDATION.md)。

可选配置：仅在 `.env` 不存在时复制 [.env.example](.env.example)，避免覆盖已有值；可修改 `PORT`、`STUDIO_DATA_DIR` 和各类中转设置。前端端口固定为 4310，开发代理跟随 `PORT`。API 和 worker 配置变化后都要重启；本轮真实开关保持 false。

```powershell
.\scripts\project.ps1 typecheck
.\scripts\project.ps1 test

.\scripts\project.ps1 doctor
```

类型检查、测试、构建已实测通过，**61 项自动测试全部通过**。doctor 是只读版本/权限/端口/空间检查，可能报告真实存在的版本不匹配。协议测试只用本地假服务与虚构密钥，不联系外部模型。最新结果见 [优化验收](docs/OPTIMIZATION_VALIDATION.md)，历史见 [M5](docs/M5_VALIDATION.md)、[M4](docs/M4_VALIDATION.md)、[M3](docs/M3_VALIDATION.md)、[M2](docs/M2_VALIDATION.md)、[M1](docs/M1_VALIDATION.md)。

构建后，在一个 PowerShell 运行 `.\scripts\project.ps1 start`，由 API 提供页面，默认访问 `http://127.0.0.1:4311/`；在另一个 PowerShell 进入同一项目目录运行 `.\scripts\project.ps1 worker`，使用相同 `.env` 数据目录执行任务。仅启动 API 时任务会停在排队中，启动 worker 后继续；不要同时占用相同端口运行 dev 与 start。当前仅面向本机使用，未配置公网身份验证。

## 操作方法

1. 左侧添加卡片，选中后在右侧编辑标题与内容。
2. 拖卡片顶部标题栏移动；选中后拖四角调整尺寸。
3. 右侧端口拖到另一张卡片左侧端口，建立文字引用。每张卡片最多一个上游文本输入，禁止循环。
4. 拖空白处平移，滚轮缩放；Shift + 拖动框选，或用底部框选工具切换模式。
5. 多选后可以一起移动或复制；底部提供删除、撤销、重做和适配内容按钮。
6. `Ctrl+Z` 撤销，`Ctrl+Shift+Z`/`Ctrl+Y` 重做，`Ctrl+C`/`Ctrl+V` 在应用内复制粘贴卡片，`Delete` 删除，`F` 适配内容，`Ctrl+S` 立即保存。输入框保留正常文字编辑行为。
7. “已保存到本地”表示内容已写入 SQLite。冲突时先导出草稿，再读取最新版本；不会自动覆盖其他页面的更改。

M2 制作流程：

1. 打开“素材库”，上传 PNG/JPEG/WebP（最多 20 MiB）或 MP4/WebM（最多 100 MiB）；视频点击后播放。
2. 在“角色”“场景”建立设定，进入编辑选择参考图片，并指定默认图。
3. 从“分镜清单”创建镜头，填写画面、景别、动作、运镜、对白、时长与图片/视频提示词，选择共享角色及场景。
4. 清单右侧上/下箭头改变剧情顺序。显示序号与手工镜头编号独立；排序不移动画布卡片。
5. Reference 节点输出选中图片，Shot 分别输出图片/视频提示词，Media 输出对应类型；拖动端口建立引用，可在属性面板检查和调整输入顺序，连线不触发生成。
6. 素材库点击“放入画布”，选中卡片后可预览并下载原文件。删除画布卡片保留设定/分镜/原文件；属性面板“移除设定/分镜”会移除业务记录，可撤销。

复制画布卡片会创建新视图并共享原设定或分镜；复制项目会重建业务记录并共享媒体原文件。可直接打开本地“雨夜来信 · M2 验收”查看三镜头案例（运行数据不随源码提交）。

M3 模拟制作流程：

1. 添加“模拟剧本拆解”，输入剧本，点击生成。成功后先预览草稿，再选择追加或替换；一次应用可撤销，不覆盖生成历史。
2. 添加“模拟图片生成”，选择主文字（例如 Shot 图片提示词），添加角色/场景图片引用，填写补充提示词及比例、候选数。右侧显示完整输入摘要，点击“开始模拟生成”才提交。
3. 任务完成后手动选择候选供下游使用；关联分镜后点击“设为镜头选用”，会同步节点与分镜最终素材。生成结果不自动选中。
4. 添加“模拟视频生成”，引用视频提示词并连接选中的图片，检查摘要后生成。结果为固定花朵测试片段，不是对所选图片进行真实图生视频。
5. 进入“任务与历史”查看固定快照、状态与错误。待确认先“重新查询”，保留同一个任务；“明确重试”创建关联的新任务。网络响应不明时“重新确认上次提交”复用请求标识。
6. “模拟异常验证”可切换明确失败、提交响应丢失、查询超时或非法分镜响应。不会自动重交生成；排队且未认领的任务可取消。
7. 修改上游图片版本、参考图或提示词后，旧结果继续保留并提示输入变化；版本切换、连线、刷新与撤销不创建任务。

本地“雨夜来信 · M3 模拟验收”包含三镜头、两次图片生成、一次视频及一次分镜草稿；镜头 01 已选用图片/视频，其他镜头仍待制作。删除节点保留任务和媒体；复制项目不复制任务/生成历史，保留授权素材和选用资产。实际接口见 [M3 API](docs/M3_API.md)。

M4 中转使用：

1. 按 [配置说明](docs/M4_CONFIGURATION.md)填写各类地址/模型/密钥；密钥只存服务端 `.env`，本轮开关保持 false。
2. 图片参考图协议与能力需明确配置；视频复制 [模板](config/video-profile.example.json)后按具体文档填写，示例路径不代表已验证服务。
3. 重启 API 和 worker；选中生成卡片，在“运行模式”选择中转站并刷新服务状态。关闭开关下可以检查配置/输入，不能真实生成。
4. 当前模式和历史来源分别标注；切换模式、刷新、连线与选择候选不执行模型调用。具体真实验收需先确定服务能力和费用额度。

## 数据与备份

V1.6 新操作及 API 见 [优化使用说明](docs/OPTIMIZATION_GUIDE.md)。任务、制作和交付记录均可定位；缺失素材映射只改当前项目引用，不改写旧任务。空间统计不执行清理。

M5 导入与交付：顶栏点击“导入 / 导出”，先检查素材包，无缺失后打包并下载；需要部分包时明确勾选“仅导出已有素材”。JSON 导入通过文件或粘贴，创建新项目，保留结构/选用引用，不带入任务或执行生成。完整用法/API 见 [M5 导入导出](docs/M5_EXPORT_IMPORT.md)。本地“雨夜来信 · M5 完整模拟交付”有三镜头和八个模拟任务；交付 ZIP 在 `output/m5/雨夜来信-M5-模拟素材包.zip`，可直接解压查看，不能当作真实模型成品。

- 默认数据库：`data/studio.sqlite`，运行时可能存在 `-wal` 和 `-shm` 文件。
- 媒体原文件和缩略图：`data/media/`；自定义 `STUDIO_DATA_DIR` 时跟随该目录。
- 中转私有回执与同步结果：`data/provider-results/`；可能保存临时签名 URL，只在服务端保管并纳入完整备份。
- 素材包与打包记录：`data/exports/`；服务端历史支持刷新找回和重新下载，不自动清理。
- `data/`、依赖、构建输出、截图和真实 `.env` 已加入 `.gitignore`。
- 备份：先停止本项目全部服务，再复制完整 `data` 目录到新的备份位置；不要运行中只复制一个数据库文件。
- 恢复：先停服务，将当前 `data` 重命名保留，再复制备份为新的 `data`，最后重启验证。
- 浏览器草稿仅辅助断线恢复；清理浏览器数据会丢失未同步草稿。
- JSON 仅包含结构与媒体引用；ZIP 仅含选用交付素材，均不是完整数据备份。换电脑导入 JSON 时缺失素材须上传并替换引用。
- 实测完整备份/独立恢复与具体 PowerShell 操作见 [备份恢复](docs/BACKUP_RESTORE.md)。原 data 未执行恢复，没有自动删除旧项目、媒体或任务。
- 当前数据库版本 5、项目文档 schemaVersion 4。V1.6 从 DB4 事务增加任务索引/worker 心跳表，不重写项目、旧快照或素材；已核对原 8 项目/13 任务/21 素材与原文件一致。升级前停 API、worker、dev 并备份整个数据目录；回退须匹配旧代码与 DB4 完整备份，不能旧代码直接读 DB5，见 [最新验收](docs/OPTIMIZATION_VALIDATION.md)。

## 当前限制

- `node:sqlite` 在 Node 24.14 输出实验特性提示，已通过读写与重启测试，升级应复测。
- 构建首屏主脚本加共享模块合计 586.49 kB，gzip 182.57 kB；面板按需加载，首屏总量并未显著减少。
- 视频容器检查不保证所有编码可播放；无转码、视频封面提取、服务端时长解析。MP4 已实测，WebM 播放与最大文件边界未完整实测。
- 素材列表检查存在性与大小，同大小损坏在预览或下载时校验发现；缺失/损坏可通过“刷新状态”和实际预览定位。
- 尚未实测具体中转站或真实 AI 效果/费用，不保证所有通用或私有协议兼容；视频模板有明确格式约束，没有余额查询/金额硬限制。模拟视频不按提示词、首帧、比例或请求时长合成。
- JSON 最大 2 MiB，不包含媒体；ZIP 原文件合计最多 1 GiB，单 API 实例一次一个包，没有 ZIP 导入、自动媒体重连或成片合成。已验证 1 GiB 边界计算、实际 32 MiB 流式包和可控写入失败，物理 1 GiB 包及真实磁盘耗尽未实测。
- 历史默认 30 条分页，1000 条夹具与旧选用版本读取通过；精确浏览器断网/关闭时点、极端租约长阻塞尚未完整验证。
- 100 节点/150 连线已采集三组生产浏览器帧间隔和渲染计数，改善及测量边界见验收，不承诺任意规模性能。2000 素材分页和同文件校验合并延期。
- 自动化虚拟剪贴板拦截 Ctrl+C/V；核心行为通过按钮和单元测试验证，真实组合键需人工复核。
- 首次源码与安装程序发布进度见 [当前索引](docs/CURRENT_PLAN.md)；第三方使用各自许可，本项目自身尚未指定开源许可。
