## 数据保护与修复

- 升级前确认本项目服务没有监听，复制完整数据到 `output/backups/before-m3-20261004-72118ccc/data`，包括 SQLite 相关文件与媒体。
- 数据库版本 3 / 文档 schemaVersion 3 已实际升级。回退先停全部服务、备份当前数据，再用旧代码配合升级前完整数据；当前没有 Git 首次提交，不提供一键代码回退承诺。
- 浏览器发现空 POST 误带 JSON Content-Type，会导致复制/重新查询失败；已改为仅有请求体时默认设置 JSON 头，并通过界面复制和重新查询验证。
- 旧迁移测试改为检查新 schemaVersion；加入 finally 关闭句柄，防止断言失败时 Windows 文件锁掩盖真正问题。

## 实际限制

- 无真实模型、无收费接口或凭证。图片为本地带标识占位图，分镜为规则模拟；视频使用随源码提供的 MDN CC0 花朵测试片段，输出不反映提示词、首帧、比例或请求时长。
- Mock 远端找回能力不能直接用于 M4；真实服务必须核实幂等、查询、费用和凭证授权。
- 服务端任务状态和进程恢复已验证；前端 HTTP 响应丢失后持久化 requestKey 的代码已实现，浏览器层网络中断/关闭发生在各精确时刻的演练尚未完整覆盖。
- 历史与任务列表目前全量返回；大量长期历史的分页和性能未验证。15 秒租约在本地短任务中验证，极端磁盘/事件循环长阻塞仍需进一步验证。
- 强制终止落盘过程可能留下孤立 `.part` 文件，不自动删除媒体；仅正常失败清理当前写入产生的文件。
- JSON 导入、CSV/ZIP 素材包尚未实现，属于 M5。M1 真实 Ctrl+C/V、100 节点性能、M2 WebM 与大文件边界仍待补充。
- 没有提交、推送或公开部署。开发服务本轮结束保留在 4310/4311；后续仍需实时核实。
