## 实际限制及后续验证

- MP4 容器检查及浏览器实际播放已验证；任意编码、WebM 播放、最大 20/100 MiB 文件和所有视频容器异常未完整实测。无转码、视频帧提取或服务端时长解析。
- 列表检查存在性与大小；同大小损坏由预览/下载时 SHA-256 校验发现。每次读取检查原文件，大视频多次 Range 请求的完整性计算开销尚未量化。
- 单文件下载端点已通过字节一致性 API 验证；浏览器“下载原文件”保存到下载目录的完整动作未单独演练。
- 进程强制终止可能留下孤立媒体；不自动清理或删除原文件。删除画布视图与移除业务记录是不同动作，均不删除磁盘素材。
- M1 真实 Ctrl+C/V、双页面冲突演练、100 节点性能仍待验证，详见历史 M1 记录。
- AI 分镜、图片/视频生成、worker、输入快照与变化标记、历史版本、最终镜头选用、JSON 导入和 ZIP 素材包尚未实现，分别在 M3～M5 推进。
