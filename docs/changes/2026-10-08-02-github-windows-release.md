# GitHub 源码与 Windows 安装程序发布

编号：CHANGE-002；版本：0.1；状态：生效。日期：2026-10-08。
基于 V1.6，生效开发方案更新为 V1.7。用户明确要求上传最新版到自己的 GitHub，并确认公开 `princefrogdida-ux/xumu-studio`、Windows 64 位安装程序；允许建立提交、推送及 Release。

## 目标与行为变化

旧行为：只在源码目录通过 Node/pnpm 启动，没有首次提交或安装程序。
新行为：公开源码仓库与 GitHub Release；下载 Setup.exe 后按当前用户安装，不需管理员权限或预装 Node/pnpm。快捷方式启动本地 API/worker，并打开现有浏览器工作台。不是 Electron 应用，不增加剪辑器或公网服务。

## 范围与实现

- 应用版本 0.1.0，方案版本 1.7；发布本地预览版，不声称真实模型闭环已验收。
- 固定 Node 24.14.0、Inno Setup 6.7.3；使用现有 esbuild 仅转译后端和共享 TypeScript，原依赖不升级。后端生产依赖按已解析版本复制，重复版本保留正确依赖关系，内置 Windows x64 sharp 原生库。
- 安装到 `%LOCALAPPDATA%\Programs\XumuStudio`；数据与私有配置在 `%LOCALAPPDATA%\XumuStudio`，可通过 XUMU_USER_DIR 指定验证路径。默认真实调用关闭。
- 启动前核实端口，冲突时不启动 worker、不终止其他进程。API/worker 保留 IPC 收尾，控制台输入 stop 或 Ctrl+C；关闭网页不停止后台工作。升级拒绝替换使用中的 node.exe。
- 卸载只处理安装文件、快捷方式和卸载项，保留用户数据/配置。不复制开发者的 data、输出、私有回执、真实 .env 或 GitHub 凭据到仓库/安装包。
- 附第三方许可、完整文件指纹、Setup SHA-256、发布说明和构建脚本。首发没有代码签名证书，不能称已签名安装包，不绕过系统安全警告。

## 验收与回退

在工作区独立目录静默安装，逐文件比对载荷；使用安装包内 Node、纯生产依赖与空数据启动 API/worker，测试保存恢复、图片/视频 Mock、素材下载/打包、同请求幂等、停止再启动。验证重复启动端口冲突不接管其他进程；验证卸载保留独立用户数据。原开发数据不参与这些故障/安装测试。

发布前类型检查、完整回归、构建及候选文件秘密排查；发布后核对远端提交、Release 附件名称/大小/SHA-256和实际下载。结果维护在 CURRENT_PLAN 与发布验证记录，不提前标完成。

回退发布可新建修复版本，或在停止后重新安装旧程序；数据库仍为 5、文档为 4，无本轮业务数据迁移。任何数据恢复先保留完整数据副本，与代码版本配套。公开源码和发布文件一旦下载无法从第三方副本撤回，因此上传前严格排除凭据与私有数据。
